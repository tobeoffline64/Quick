## 1. Executive Summary & Architecture Scope

Milestone 2 delivers the full **Material Design 3 (Material You / M3)** base component suite and associated rendering engine extensions for the Quick UI Framework. Building directly upon the Milestone 1 Dynamic HCT Color Engine (`quick-style`), Milestone 2 implements:

1. **`Button` Component (`quick-widgets::button`)**:
   - Complete implementation of all **5 M3 button variants**: `Filled`, `Tonal`, `Elevated`, `Outlined`, and `Text`.
   - **Pill geometry** (`corner-full` radius $= 9999.0\text{px}$ / `bounds.size.height / 2.0`).
   - **State layer feedback system** (8% Hover, 12% Focus, 12% Pressed, 16% Dragged, 38% Disabled content / 12% Disabled container).
   - **Dynamic color role mapping** to M3 tokens (`primary`/`on_primary`, `secondary_container`/`on_secondary_container`, `surface_container_low`/`primary`, `outline`/`primary`).
   - Leading/trailing icon support and responsive layout sizing.

2. **`Card` Component (`quick-widgets::card`)**:
   - Complete implementation of all **3 M3 card variants**: `Elevated`, `Filled`, and `Outlined`.
   - **Elevation Levels 0 through 5** with dual-pass ambient ($15\%$ alpha) and key ($30\%$ alpha) drop shadows.
   - **Dynamic surface tinting** ($0\%\dots 14\%$) blended with `surface_tint` role based on elevation height.
   - **M3 shape radiuses**: `corner-medium` ($12.0\text{px}$) and `corner-large` ($16.0\text{px}$).
   - Hierarchical container nesting, flexible layout, and bubbling pointer hit-testing.

3. **`quick-render` Canvas & Rasterizer Extensions**:
   - First-class drop shadow and surface tint APIs on `Canvas` (`draw_shadow`, `draw_drop_shadow`, `draw_elevation_shadow`, `fill_surface_tint`).
   - New `DrawCommand` variants (`DrawDropShadow`, `DrawShadow`).
   - Sub-millisecond CPU software rasterization for soft rounded-rectangle drop shadows using analytical Signed Distance Field (SDF) falloff.
   - Skia hardware backend mapping (`skia_safe::MaskFilter::blur` and `ImageFilter::drop_shadow`).

4. **Declarative Markup & Dynamic Theming (`quick-markup`)**:
   - Support for `variant="..."` attributes on `<Button>` and `<Card>` in `.quick` templates.
   - Automatic cascade of M3 CSS rules generated by `ThemePackage::generate_css()`.

## 2. Component Blueprint: `Button` (`quick-widgets::button`)

### 2.1 Specification & M3 Variant Matrix

Material 3 defines 5 distinct button variants tailored for differing hierarchy levels:

| Variant | Emphasis | Container Color | Content / Label Color | State Layer Overlay | Elevation (Resting $\to$ Hover) | Border |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`Filled`** *(Default)* | High | `color_scheme.primary` | `color_scheme.on_primary` | `on_primary` ($8\% \text{H}, 12\% \text{P}$) | Level $0 \to$ Level 1 | None |
| **`Tonal`** | Medium-High | `color_scheme.secondary_container` | `color_scheme.on_secondary_container` | `on_secondary_container` ($8\% \text{H}, 12\% \text{P}$) | Level $0 \to$ Level 1 | None |
| **`Elevated`** | Medium-Low | `color_scheme.surface_container_low` | `color_scheme.primary` | `primary` ($8\% \text{H}, 12\% \text{P}$) | Level $1 \to$ Level 2 (with dual shadow) | None |
| **`Outlined`** | Medium | `Color::TRANSPARENT` | `color_scheme.primary` | `primary` ($8\% \text{H}, 12\% \text{P}$) | Level 0 | $1\text{px}$ `outline` (or `outline_variant`) |
| **`Text`** | Low | `Color::TRANSPARENT` | `color_scheme.primary` | `primary` ($8\% \text{H}, 12\% \text{P}$) | Level 0 | None |

### 2.2 Geometry & Dimensions
- **Shape**: Pill geometry (`BorderRadius::all(9999.0)` or `bounds.size.height / 2.0`).
- **Standard Height**: $40.0\text{px}$.
- **Standard Padding**:
  - `Filled`, `Tonal`, `Elevated`, `Outlined`: `Insets::symmetric(10.0, 24.0)` (Vertical $10\text{px}$, Horizontal $24\text{px}$).
  - `Text`: `Insets::symmetric(10.0, 16.0)` (Vertical $10\text{px}$, Horizontal $16\text{px}$).
- **Typography**: M3 Label Large ($14.0\text{px}$, font-weight $500$).
- **Layout Measurement Bounds**:
  - Estimated width: $(\text{char\_count} \times \text{font\_size} \times 0.55 + \text{pad\_h}).\max(60.0)$.
  - Estimated height: $\text{font\_size} \times 1.3 + \text{pad\_v}$ (defaulting to $\approx 40.0\text{px}$).

### 2.3 State Layer System (`md-sys-state`)
The state layer is a semi-transparent overlay in the color of the button's content:
- **Hover**: $8\%$ opacity (`StateLayerTokens::M3.hover = 0.08`).
- **Focus**: $12\%$ opacity (`StateLayerTokens::M3.focus = 0.12`).
- **Pressed / Active**: $12\%$ opacity (`StateLayerTokens::M3.pressed = 0.12`).
- **Disabled**:
  - Container: $12\%$ opacity of `on_surface` (or container background dimmed to $12\%$).
  - Content: $38\%$ opacity of `on_surface`.

```rust
impl Widget for Button {
    fn build_layout(&mut self, engine: &mut LayoutEngine) -> Result<NodeId, TaffyError> {
        let font_size = self.style.font_size.unwrap_or(14.0);
        let char_count = self.text.chars().count() as f32;
        let pad_h = self.style.padding.map(|p| p.left + p.right).unwrap_or_else(|| {
            if self.variant == ButtonVariant::Text { 32.0 } else { 48.0 }
        });
        let pad_v = self.style.padding.map(|p| p.top + p.bottom).unwrap_or(20.0);

        let estimated_width = (char_count * font_size * 0.55 + pad_h).max(60.0);
        let estimated_height = font_size * 1.3 + pad_v;

        let mut computed_style = self.style.clone();
        if computed_style.width.is_none() {
            computed_style.width = Some(Dimension::Px(estimated_width));
        }
        if computed_style.height.is_none() {
            computed_style.height = Some(Dimension::Px(estimated_height));
        }

        engine.new_leaf(&computed_style)
    }

    fn paint(&self, canvas: &mut Canvas, bounds: Rect) {
        let state_tokens = StateLayerTokens::M3;
        let elev_tokens = ElevationTokens::default();

        // 1. Determine Default Colors based on Variant
        let (default_bg, default_fg, default_border, default_border_w) = match self.variant {
            ButtonVariant::Filled => (
                Color::from_hex("#6750A4").unwrap(),
                Color::WHITE,
                None,
                None,
            ),
            ButtonVariant::Tonal => (
                Color::from_hex("#E8DEF8").unwrap(),
                Color::from_hex("#1D192B").unwrap(),
                None,
                None,
            ),
            ButtonVariant::Elevated => (
                Color::from_hex("#F7F2FA").unwrap(),
                Color::from_hex("#6750A4").unwrap(),
                None,
                None,
            ),
            ButtonVariant::Outlined => (
                Color::TRANSPARENT,
                Color::from_hex("#6750A4").unwrap(),
                Some(Color::from_hex("#79747E").unwrap()),
                Some(1.0),
            ),
            ButtonVariant::Text => (
                Color::TRANSPARENT,
                Color::from_hex("#6750A4").unwrap(),
                None,
                None,
            ),
        };

        // Style overrides take precedence if set
        let base_bg = self.style.background_color.unwrap_or(default_bg);
        let text_color = self.style.text_color.unwrap_or(default_fg);
        let border_color = self.style.border_color.or(default_border);
        let border_width = self.style.border_width.or(default_border_w);
        let radius = self.style.border_radius.unwrap_or(BorderRadius::all(bounds.size.height / 2.0));

        // 2. Draw Elevation Shadows for Elevated Variant
        if self.variant == ButtonVariant::Elevated && base_bg != Color::TRANSPARENT {
            let level = if self.is_pressed || self.is_hovered { 2 } else { 1 };
            canvas.draw_elevation_shadow(bounds, radius, level, &elev_tokens);
        }

        // 3. Compute State Layer Overlay on Background
        let mut final_bg = base_bg;
        if self.disabled {
            final_bg = state_tokens.apply_disabled_container(base_bg);
        } else if base_bg != Color::TRANSPARENT {
            if self.is_pressed {
                final_bg = state_tokens.apply_pressed(base_bg, text_color);
            } else if self.is_hovered {
                final_bg = state_tokens.apply_hover(base_bg, text_color);
            } else if self.is_focused {
                final_bg = state_tokens.apply_focus(base_bg, text_color);
            }
        }

        // 4. Paint Background
        if final_bg != Color::TRANSPARENT {
            canvas.fill_rounded_rect(bounds, radius, final_bg);
        }

        // 5. Paint Border
        if let (Some(b_color), Some(b_width)) = (border_color, border_width) {
            if b_width > 0.0 {
                canvas.stroke_rounded_rect(bounds, radius, b_color, b_width);
            }
        }

        // 6. Paint Text Label & Icon
        let final_fg = if self.disabled {
            state_tokens.apply_disabled_content(text_color)
        } else {
            text_color
        };

        let font_size = self.style.font_size.unwrap_or(14.0);
        let char_count = self.text.chars().count() as f32;
        let text_w = char_count * font_size * 0.55;
        let origin_x = bounds.origin.x + ((bounds.size.width - text_w) / 2.0).max(0.0);
        let origin_y = bounds.origin.y + ((bounds.size.height + font_size * 0.8) / 2.0);

        canvas.draw_text(
            &self.text,
            Point::new(origin_x, origin_y),
            final_fg,
            font_size,
            self.style.font_family.clone(),
        );
    }
}
```

## 3. Component Blueprint: `Card` (`quick-widgets::card`)

### 3.1 Specification & M3 Variant Matrix

Material 3 defines 3 card variants for grouping content:

| Variant | Purpose | Container Color | Elevation Level | Dual Shadow | Surface Tint | Border |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`Elevated`** | Prominent floating surface | `surface_container_low` | Level 1 (0–5 configurable) | Key ($30\%$) + Ambient ($15\%$) | $5\%\dots 14\%$ | None |
| **`Filled`** | Higher-contrast solid container | `surface_container_highest` | Level 0 | None | $0\%$ | None |
| **`Outlined`** | Clean delimited surface | `surface` (or `surface_container_lowest`) | Level 0 | None | $0\%$ | $1\text{px}$ `outline_variant` |

### 3.2 Elevation Levels (0–5) & Dual-Pass Shadows

Elevation provides depth via two combined shadow passes:
1. **Key Shadow (Directional)**: Simulates overhead key light. Creates a crisp, downward offset ($0\text{--}4\text{px}$) with $30\%$ alpha (`rgba(0,0,0,77)`).
2. **Ambient Shadow (Diffuse)**: Simulates ambient light bounce. Creates a soft, symmetric glow ($1\text{--}12\text{px}$ blur, $1\text{--}6\text{px}$ spread) with $15\%$ alpha (`rgba(0,0,0,38)`).

| Level | Elevation DP | Key Shadow | Ambient Shadow | Surface Tint Opacity |
| :--- | :--- | :--- | :--- | :--- |
| **Level 0** | $0\text{ dp}$ | `None` | `None` | $0\%$ |
| **Level 1** | $1\text{ dp}$ | `0px 1px 2px 0px rgba(0,0,0,0.30)` | `0px 1px 3px 1px rgba(0,0,0,0.15)` | $5\%$ |
| **Level 2** | $3\text{ dp}$ | `0px 1px 2px 0px rgba(0,0,0,0.30)` | `0px 2px 6px 2px rgba(0,0,0,0.15)` | $8\%$ |
| **Level 3** | $6\text{ dp}$ | `0px 1px 3px 0px rgba(0,0,0,0.30)` | `0px 4px 8px 3px rgba(0,0,0,0.15)` | $11\%$ |
| **Level 4** | $8\text{ dp}$ | `0px 2px 3px 0px rgba(0,0,0,0.30)` | `0px 6px 10px 4px rgba(0,0,0,0.15)` | $12\%$ |
| **Level 5** | $12\text{ dp}$ | `0px 4px 4px 0px rgba(0,0,0,0.30)` | `0px 8px 12px 6px rgba(0,0,0,0.15)` | $14\%$ |

### 3.3 Dynamic Surface Tinting
At elevation $> 0$, the container background is dynamically blended with `surface_tint` (derived from the primary color):
$$\text{Color}_{\text{tinted}} = \text{base\_surface} \times (1 - \alpha) + \text{surface\_tint} \times \alpha$$
Where $\alpha \in \{0.0, 0.05, 0.08, 0.11, 0.12, 0.14\}$.

### 3.4 Corner Radiuses & Layout Dimensions
- **Shape Tokens**: `corner-large` ($16.0\text{px}$) by default, or `corner-medium` ($12.0\text{px}$) for compact dialog cards.
- **Padding**: `Insets::all(24.0)` (or `16.0px` for dense layouts).
- **Gap**: $16.0\text{px}$ vertical child spacing.
- **Flex Direction**: `FlexDirection::Column`.

## 4. Engine Blueprint: `quick-render` Drop Shadow & Surface Tint Extensions

### 4.1 `Canvas` Display Command Extensions

To support dual-pass shadows and surface tinting with zero runtime overhead, we extend `Canvas` and `DrawCommand`:

```rust
use quick_core::geometry::{BorderRadius, Color, Point, Rect};
use quick_style::theme::tokens::{ElevationLevel, ElevationTokens, Shadow};

#[derive(Debug, Clone)]
pub enum DrawCommand {
    Clear(Color),
    FillRect(Rect, Color),
    StrokeRect(Rect, Color, f32),
    FillRoundedRect(Rect, BorderRadius, Color),
    StrokeRoundedRect(Rect, BorderRadius, Color, f32),
    DrawShadow {
        rect: Rect,
        radius: BorderRadius,
        shadow: Shadow,
    },
    DrawText {
        text: String,
        origin: Point,
        color: Color,
        font_size: f32,
        font_family: Option<String>,
    },
    DrawLine {
        start: Point,
        end: Point,
        color: Color,
        width: f32,
    },
    PushClip(Rect),
    PopClip,
    Save,
    Restore,
    Translate(f32, f32),
    Scale(f32, f32),
}

impl Canvas {
    /// Records a single box shadow layer
    pub fn draw_shadow(&mut self, rect: Rect, radius: BorderRadius, shadow: Shadow) {
        self.commands.push(DrawCommand::DrawShadow { rect, radius, shadow });
    }

    /// Records dual-pass elevation shadow (key + ambient)
    pub fn draw_elevation_shadow(
        &mut self,
        rect: Rect,
        radius: BorderRadius,
        level: u8,
        elevation_tokens: &ElevationTokens,
    ) {
        let elev = elevation_tokens.get(level);
        if let Some(ambient) = elev.ambient_shadow {
            self.draw_shadow(rect, radius, ambient);
        }
        if let Some(key) = elev.key_shadow {
            self.draw_shadow(rect, radius, key);
        }
    }

    /// Helper to fill rounded rect with dynamic surface tint overlay
    pub fn fill_surface_tint(
        &mut self,
        rect: Rect,
        radius: BorderRadius,
        base_color: Color,
        tint_color: Color,
        opacity: f32,
    ) {
        let opacity_clamped = opacity.clamp(0.0, 1.0);
        let r = (base_color.r as f32 * (1.0 - opacity_clamped) + tint_color.r as f32 * opacity_clamped).round() as u8;
        let g = (base_color.g as f32 * (1.0 - opacity_clamped) + tint_color.g as f32 * opacity_clamped).round() as u8;
        let b = (base_color.b as f32 * (1.0 - opacity_clamped) + tint_color.b as f32 * opacity_clamped).round() as u8;
        let final_color = Color::from_rgba(r, g, b, base_color.a);
        self.fill_rounded_rect(rect, radius, final_color);
    }
}
```

### 4.2 Software Rasterizer Analytical Drop Shadow Implementation

In `SoftwareRasterizer::render_to_buffer`, shadows are rendered accurately and quickly on CPU using an analytical distance field algorithm:

```rust
// In quick_render::rasterizer
impl SoftwareRasterizer {
    pub fn draw_shadow(
        buffer: &mut [u32],
        width: u32,
        height: u32,
        rect: Rect,
        radius: BorderRadius,
        shadow: Shadow,
        clip: Rect,
    ) {
        if shadow.color.a == 0 {
            return;
        }

        // Calculate expanded shadow bounding box
        let offset_x = shadow.offset_x;
        let offset_y = shadow.offset_y;
        let spread = shadow.spread_radius;
        let blur = shadow.blur_radius.max(0.5);

        let shadow_rect = Rect::new(
            rect.origin.x + offset_x - spread,
            rect.origin.y + offset_y - spread,
            rect.size.width + spread * 2.0,
            rect.size.height + spread * 2.0,
        );

        let pad = blur * 2.0;
        let min_x = (shadow_rect.min_x() - pad).max(clip.min_x()).max(0.0) as i32;
        let min_y = (shadow_rect.min_y() - pad).max(clip.min_y()).max(0.0) as i32;
        let max_x = (shadow_rect.max_x() + pad).min(clip.max_x()).min(width as f32) as i32;
        let max_y = (shadow_rect.max_y() + pad).min(clip.max_y()).min(height as f32) as i32;

        let center_x = shadow_rect.origin.x + shadow_rect.size.width / 2.0;
        let center_y = shadow_rect.origin.y + shadow_rect.size.height / 2.0;
        let half_w = shadow_rect.size.width / 2.0;
        let half_h = shadow_rect.size.height / 2.0;
        let r = radius.top_left.min(half_w).min(half_h);

        let shadow_color = shadow.color;

        for y in min_y..max_y {
            let py = y as f32 + 0.5;
            let dy = (py - center_y).abs() - (half_h - r);

            for x in min_x..max_x {
                let px = x as f32 + 0.5;
                let dx = (px - center_x).abs() - (half_w - r);

                // Compute distance to rounded corner
                let dist = if dx > 0.0 && dy > 0.0 {
                    (dx * dx + dy * dy).sqrt() - r
                } else {
                    dx.max(dy) - r
                };

                // Analytical Gaussian / Smoothstep falloff
                let alpha_factor = if dist <= -blur {
                    1.0
                } else if dist >= blur {
                    0.0
                } else {
                    let t = (dist + blur) / (2.0 * blur);
                    (1.0 - t).clamp(0.0, 1.0)
                };

                if alpha_factor > 0.005 {
                    let pixel_alpha = ((shadow_color.a as f32) * alpha_factor).round() as u8;
                    let pixel_color = Color::from_rgba(
                        shadow_color.r,
                        shadow_color.g,
                        shadow_color.b,
                        pixel_alpha,
                    );
                    Self::set_pixel(buffer, width, height, x, y, pixel_color, clip);
                }
            }
        }
    }
}
```

### 4.3 Hardware Accelerated Pipeline (Skia Backend)

In `RenderPipeline::render_to_skia`, `DrawCommand::DrawShadow` maps directly to Skia's blur mask filter:

```rust
#[cfg(feature = "skia")]
DrawCommand::DrawShadow { rect, radius, shadow } => {
    use skia_safe::{Color4f, MaskFilter, BlurStyle, Paint, PaintStyle, RRect, Rect as SkRect};
    if shadow.color.a > 0 {
        let mut paint = Paint::default();
        paint.set_style(PaintStyle::Fill);
        paint.set_anti_alias(true);
        paint.set_color4f(
            Color4f::new(
                shadow.color.r as f32 / 255.0,
                shadow.color.g as f32 / 255.0,
                shadow.color.b as f32 / 255.0,
                shadow.color.a as f32 / 255.0,
            ),
            None,
        );

        if shadow.blur_radius > 0.0 {
            let sigma = shadow.blur_radius * 0.57735 + 0.5;
            paint.set_mask_filter(MaskFilter::blur(BlurStyle::Normal, sigma, false));
        }

        let spread = shadow.spread_radius;
        let sk_rect = SkRect::from_xywh(
            rect.origin.x + shadow.offset_x - spread,
            rect.origin.y + shadow.offset_y - spread,
            rect.size.width + spread * 2.0,
            rect.size.height + spread * 2.0,
        );
        let rrect = RRect::new_rect_radii(
            sk_rect,
            &[
                skia_safe::Vector::new(radius.top_left, radius.top_left),
                skia_safe::Vector::new(radius.top_right, radius.top_right),
                skia_safe::Vector::new(radius.bottom_right, radius.bottom_right),
```

```rust
// Button Parsing in build_node
"Button" => {
    let text_val = node.text.as_deref().unwrap_or("Button");
    let variant = match node.attributes.get("variant").map(|s| s.to_lowercase()).as_deref() {
        Some("tonal") => ButtonVariant::Tonal,
        Some("elevated") => ButtonVariant::Elevated,
        Some("outlined") => ButtonVariant::Outlined,
        Some("text") => ButtonVariant::Text,
        _ => ButtonVariant::Filled,
    };

    let mut btn = Button::new(text_val).with_variant(variant);
    btn.id = node.id.clone();
    btn.classes = classes;
    btn.style.merge_with(&computed_style);

    let action_opt = node.on_click.as_ref()
        .or_else(|| node.attributes.get("onclick"))
        .or_else(|| node.attributes.get("on_click"));

    if let Some(action_name) = action_opt {
        let clean_name = action_name.trim_end_matches("()").trim();
        if let Some(handler) = data_ctx.action_handlers.get(clean_name) {
            let handler_cl = handler.clone();
            btn.on_click = Some(Box::new(move || {
                (handler_cl.borrow_mut())();
            }));
        }
    }
    Box::new(btn)
}

// Card Parsing in build_node
"Card" => {
    let variant = match node.attributes.get("variant").map(|s| s.to_lowercase()).as_deref() {
        Some("filled") => CardVariant::Filled,
        Some("outlined") => CardVariant::Outlined,
        _ => CardVariant::Elevated,
    };

    let elevation = node.attributes.get("elevation")
        .and_then(|v| v.parse::<u8>().ok())
        .unwrap_or_else(|| if variant == CardVariant::Elevated { 1 } else { 0 });

    let mut card = Card::new(variant).with_elevation(elevation);
    card.container.id = node.id.clone();
    card.container.classes = classes;
    card.container.style.merge_with(&computed_style);

    for child_node in &node.children {
        let child_widget = build_node(child_node, data_ctx, stylesheet);
        card.add_child(child_widget);
    }
    Box::new(card)
}
```

## 6. Implementation Risk & Backward Compatibility Analysis

1. **Existing Unit and E2E Tests**:
   - `tests/e2e_m3_widgets.rs` tests `Button` and `Card` styling by directly assigning `btn.style.background_color` and `btn.style.border_radius`.
   - **Requirement**: In `Button::paint` and `Card::paint`, explicit `self.style.*` properties MUST override default variant values.
   - For `CardVariant::Elevated`, `canvas.commands().len()` must be $\ge 4$ (shadow command, container background, and child draw commands).
2. **Hit Testing on Elevated Surfaces**:
   - Dropped shadows must NOT capture pointer events. Only the inner container bounds `bounds.contains(pos)` should participate in hit testing and event routing.
3. **No Dynamic Heap Allocation per Frame**:
   - All shadow computations are purely stack-allocated arithmetic with zero heap allocations, ensuring frame times remain $<1.0\text{ms}$.
